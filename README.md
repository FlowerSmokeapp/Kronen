# Budgie – budget for unge

Enkel budget-app for unge: én stor cirkel viser, hvor mange penge du har tilbage denne måned.

- Løn, lommepenge og faste udgifter
- Kategorier med grænser og advarsler
- Sparemål
- Månedsrapport, årsoverblik og eksport til Excel (Premium)
- Login med e-mail eller Google – data gemmes i Firebase
- Kan gemmes på hjemmeskærmen (PWA)

Live: https://flowersmokeapp.github.io/Kronen/

Login slås til ved at udfylde `firebase-config.js` og bruge reglerne i `firestore.rules`.
